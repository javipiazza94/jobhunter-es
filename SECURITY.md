# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in JobHunter, please report it responsibly.

Do **NOT** file a public issue on GitHub. Instead, please contact the repository maintainers directly or use GitHub's private vulnerability reporting feature on the repository page.

Please include:
- A description of the issue and potential impact.
- Step-by-step reproduction instructions or proof-of-concept.
- Suggested mitigations if known.

We appreciate your assistance in keeping JobHunter safe for everyone.
